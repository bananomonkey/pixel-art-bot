# pixel-art-bot

Telegram-бот: превращает присланные фото в пиксель-арт. Нейросетей нет —
только классическая обработка изображений (Pillow, numpy): BOX-усреднение
до сетки, квантизация (k-means или сопоставление с фиксированной палитрой
по расстоянию redmean), дизеринг, увеличение NEAREST до квадратов без
интерполяции.

## Использование

1. Прислать фото (сжатое или файлом jpg/png/webp), статичный стикер или
   GIF/MP4 (берётся первый кадр).
2. Бот отвечает результатом с настройками по умолчанию: сетка 96 px,
   палитра «Авто (16 цветов)», дизеринг выключен.
3. Стиль меняется кнопками под результатом; картинка перерисовывается
   редактированием того же сообщения, новое не отправляется.

Клавиатура разделена на категории:

| Категория | Содержимое |
| --- | --- |
| Главный экран | Размер пикселя (4 пресета и свой), категории, случайный стиль, демо, сброс |
| Палитры | Авто (8–64 цвета), Game Boy, NES, PICO-8, C64, Ч/Б, 1-bit, ZX Spectrum, Sweetie 16, CGA, своя |
| Коррекции | Дизеринг (выкл / Floyd–Steinberg / Аткинсон / Байер 8×8), чёткость деталей, контраст, насыщенность, резкость, сброс |
| Эффекты | Обводка (тёмная или объёмная), сканлайны, зерно, подсветка сетки |
| Кадр | Вырезка фона (порог подбирается автоматически), кадрирование (весь кадр / объект крупно / объект с полем), бесшовный тайл (блендинг / зеркало), проверка стыков 3×3 |
| Экспорт | Сохранение стиля, PNG без пережатия, стикер 512 px, водяной знак |
| Свой размер | Сетка −/+ с шагом 8, сохранить как свой, ввод числа 8–256 |

Параметры:

- Вырезка фона — заливка от краёв кадра: проходит по плавным переходам
  (виньетка, мягкая тень) и останавливается на резких краях объекта.
  Применяется, когда фон однороден по периметру кадра; на пёстрых сценах
  выключается автоматически. Порог подбора настраивать не нужно.
- Стикер — файл со стороной 512 px, прозрачный, если фон вырезан.
- Водяной знак — текст из переменной `WATERMARK_TEXT`.
- `/palette` — своя палитра: hex-цвета текстом, файл .hex (lospec) или фото
  (до 64 основных цветов).
- `/grid N` — свой размер сетки для последнего результата.
- Исходник хранится в памяти 30 минут (TTL скользящий), затем бот просит
  прислать фото заново.

Команды: `/start`, `/help`, `/palette`, `/mystyle`, `/demo`, `/grid N`,
`/pack`, `/packdone`, `/packset`, `/packcancel`, `/sheet`, `/sheetdone`,
`/sheetcancel`; админские — `/admin`, `/ban`, `/unban`, `/cancel`.

Список команд задаётся ботом автоматически при запуске (set_my_commands);
вручную его вводить в BotFather не нужно.

## Ассет-паки текстур

Пакетный режим для игр: несколько фото превращаются в бесшовные тайлы.

1. `/pack` — включить режим.
2. Прислать фото-текстуры (до 20). Обычная пикселизация в этом режиме
   отключена; индивидуальные настройки не применяются.
3. `/packdone` — сборка: zip с тайлами и превью-простыня. `/packcancel` — отмена.

Настройки `/packset` (сохраняются на пользователя):

| Параметр | Значения |
| --- | --- |
| Размер тайла | 16, 32, 64, 128 (степени двойки) |
| Бесшовность | Блендинг (циклический сдвиг + ромбовидная маска), зеркало, выкл |
| Палитра | Авто (одна общая на весь пак), своя, фиксированная |
| Дизеринг | Выкл, Floyd–Steinberg, Аткинсон, Байер 8×8 |
| Авто-тайлы | Режим: ровно 2 фото, на выходе 16 тайлов переходов (blob-схема) |

Состав архива на каждый тайл: PNG нативного размера (без апскейла — движки
масштабируют сами), normal map (градиенты Собеля по яркости, ориентация Y+
вверх, для 2D-освещения в Unity/Godot), color map 4×4 для миникарт и LOD.
Дополнительно: палитра пака в форматах .gpl (GIMP, Aseprite) и .hex.
Прозрачность исходных PNG сохраняется. Имена файлов в архиве берутся из имён
присланных файлов.

Пайплайн тайла: центральный кроп 1:1, уменьшение до сетки, бесшовность
до квантизации и дизеринга, общая палитра, запись PNG. Дизеринг Floyd–Steinberg
и Аткинсон применяются к массиву 3×3 с вырезанием центра — ошибка
распространяется через швы.

Кнопка «Проверка 3×3» в категории «Кадр» показывает текущий результат
в мозаике 3×3 прямо в чате.

## Спрайт-листы

`/sheet` — включить режим, прислать GIF или MP4, `/sheetdone` — сборка.
Кадры (до 12, равномерно по длительности) пикселизируются в одной общей
палитре и склеиваются в горизонтальную ленту PNG нативного размера.
Настройки сетки, палитры и дизеринга общие с паком (`/packset`).
`/sheetcancel` — отмена.

## Админ-панель и рассылки

Доступ по Telegram ID из переменной окружения `ADMIN_IDS` (через запятую).
Без переменной панель закрыта для всех.

```bash
ADMIN_IDS=123456789,987654321 BOT_TOKEN=<токен> python main.py
```

Возможности панели `/admin`:

- Новая рассылка: пост следующим сообщением, затем разовая («через 30м»),
  циклическая («каждые 2ч») или целевая — только чатам с активностью за
  N дней. Интервалы: `30м`, `1ч30м`, `1д`; пределы от 1 минуты до 30 дней.
- Список активных рассылок с отменой.
- Шаблоны постов с отправкой одним нажатием.
- Статистика за 14 дней: фото, пользователи, отправки.
- Баны: `/ban` (реплаем или по ID) и `/unban`; забаненные игнорируются
  и исключаются из рассылок.

Механика: пост копируется через `copy_message` в чаты из LRU-реестра
(до 10 000; заблокировавшие бота исключаются автоматически), скорость
20 сообщений/сек, до 20 активных рассылок и 20 шаблонов. Всё хранится
в памяти процесса и сбрасывается при перезапуске — файловая система хостинга
эфемерна. Отмена ввода — `/cancel`.

## Палитры

- Авто — k-means по уменьшенной сетке, N цветов (8–64).
- Game Boy — 4 оттенка зелёного.
- NES — палитра 2C02, 54 цвета.
- PICO-8 — 16 цветов.
- C64 — 16 цветов (палитра Pepto).
- Ч/Б — серая шкала, 8 уровней; 1-bit — 2 уровня.
- ZX Spectrum — 15 цветов; Sweetie 16 — 16 цветов.
- CGA — палитра 1: чёрный, циан, маджента, белый.

Для фиксированных палитр пиксель заменяется ближайшим цветом по redmean
(взвешенное RGB-расстояние), векторно в numpy.

## Структура

```
main.py            точка входа (long polling, проверка BOT_TOKEN)
bot/
  config.py        конфигурация (os.getenv: BOT_TOKEN, ADMIN_IDS, WATERMARK_TEXT)
  palettes.py      фиксированные палитры, разбор hex
  pixelart.py      обработка изображений (без зависимостей от aiogram)
  pack.py          ассет-паки: настройки, сессии, сборка zip
  state.py         состояние: настройки (LRU 200, TTL 30 мин), реестр чатов
  broadcast.py     логика рассылок: интервалы, расписание, шаблоны
  admin.py         админ-панель, рассылки, статистика, баны
  handlers.py      хэндлеры aiogram 3.x, клавиатура, редактирование
tests/             pytest
```

## Запуск

Обязательная переменная — `BOT_TOKEN` (токен от @BotFather). Необязательные:
`ADMIN_IDS`, `WATERMARK_TEXT`.

```bash
pip install -r requirements.txt
BOT_TOKEN=123456:ABC-DEF python main.py
```

Без `BOT_TOKEN` процесс завершается с сообщением об ошибке в логе.

## Деплой на bothost.ru

1. `git clone https://github.com/bananomonkey/pixel-art-bot.git && cd pixel-art-bot`
2. `pip install -r requirements.txt` (Python 3.11+, рекомендуется venv)
3. Задать `BOT_TOKEN` и запустить `python main.py`; в панели хостинга —
   точка входа `main.py`, переменная окружения `BOT_TOKEN`.
4. Вариант с Docker: `docker build -t pixel-art-bot . && docker run -e BOT_TOKEN=<токен> pixel-art-bot`.

Диск не используется: фото, результаты и состояние находятся в памяти.
Исходники хранятся уменьшенными до 1024 px в сжатом виде. Обработка
ограничена семафором (2 одновременно), антиспам — 1 фото в 3 секунды
на пользователя.

## Ограничения

- Файлы до 20 МБ и до 4000×4000 px; вход уменьшается до 1024 px.
- Из анимаций берётся первый кадр (MP4 — через imageio-ffmpeg).
- Видеостикеры и анимированные стикеры не поддерживаются.
- Вырезка фона и бесшовность работают без нейросетей: лучше всего
  на однотонных фонах и текстурах с мягкой структурой; для жёстких узоров
  (плитка, кирпич) подходит режим «зеркало».
- Фото и результаты не пишутся на диск и не логируются; в логах нет
  user_id и содержимого.

## Тесты

```bash
pip install pytest
pytest
```

Тестовые изображения генерируются программно, внешние файлы не используются.
