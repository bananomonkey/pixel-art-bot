# pixel-art-bot

Telegram-бот, который превращает присланные фото в пиксель-арт **без ИИ** — только
классическая обработка изображений (Pillow + numpy): BOX-усреднение до сетки,
квантизация цветов (mediancut или сопоставление с фиксированной палитрой по
восприимчивому расстоянию redmean), дизеринг Bayer/Floyd–Steinberg и увеличение
NEAREST до ровных квадратов.

## Как пользоваться

1. Пришли фото (сжатое или файл jpg/png/webp), **стикер** или **GIF**
   (GIF/MP4-анимация → берётся первый кадр).
2. Сразу получишь пиксель-арт с настройками по умолчанию:
   размер «Средний» (сетка 96 px), палитра «Авто (16 цветов)», дизеринг выключен.
3. Меняй стиль кнопками под результатом — картинка перерисуется **на месте**
   (редактирование того же сообщения).

Кнопки:

| Ряд | Кнопки |
| --- | --- |
| Размер пикселя | Мелкий (128 px) · Средний (96 px) · Крупный (64 px) · Огромный (32 px) |
| Палитра | Авто (N цветов) · Game Boy · NES · PICO-8 · C64 · Ч/Б · CGA · Свои |
| Опции | Дизеринг вкл/выкл · Больше цветов · Меньше цветов |
| Коррекции | Контраст −/+ · Насыщенность −/+ |
| Резкость | Резкость −/+ · 🔖 Запомнить · 🎲 Демо |
| Действия | 📎 Скачать PNG (без пережатия) · 🎲 Другой стиль · ↺ Сброс корр. |

- **🔖 Запомнить** сохраняет текущий стиль — он применяется ко всем новым фото
  (`/mystyle` — посмотреть/сбросить).
- **Свои палитры** (`/palette`): пришли hex-цвета (`#FF004D 00E436 7E2553`)
  или фото — бот возьмёт до 64 основных цветов; кнопка «Свои» применяет палитру.
- **Инлайн-режим**: `@bot_game ...` в любом чате — примеры стилей для шаринга
  (нужно один раз включить inline у @BotFather: `/setinline`).
- **🎲 Демо** обрабатывает встроенную тестовую картинку текущим стилем; `/demo`
  — случайный стиль.
- Исходник хранится в памяти 30 минут (скользящий TTL); после — «Исходное фото
  устарело, пришли его заново».

Команды: `/start`, `/help`, `/palette`, `/mystyle`, `/demo` — для всех;
`/admin`, `/ban`, `/unban`, `/cancel` — для админов (см. ниже).

## Админ-панель и рассылки

Доступ по Telegram ID: задай переменную окружения `ADMIN_IDS` (можно несколько,
через запятую). Без неё панель закрыта для всех.

```bash
ADMIN_IDS=123456789,987654321 BOT_TOKEN=<токен> python main.py
```

Узнать свой ID можно через @userinfobot или любой подобный сервис.

Панель: `/admin` →

- **📢 Новая рассылка** — отправь пост следующим сообщением (текст, фото,
  видео — что угодно; не альбом), затем выбери:
  - **⏱ Разовая** — «через сколько отправить»: `30м`, `1ч30м`, `1д`…;
  - **🔁 Циклическая** — «с каким интервалом»: `30м`, `2ч`, `1д`…;
  - **🎯 Разово активным за N дней** — только чатам с активностью за период;
  - **❌ Отменить пост** — сбросить черновик.
- **📋 Рассылки** — список активных с отменой по кнопке.
- **💾 Шаблоны** — сохранённые посты с кнопкой «📤 отправить» (идёт в фоне).
- **📈 По дням** — статистика за 14 дней: фото, пользователи, отправки (барами).
- **🚫 Баны** — `/ban` (реплаем на сообщение пользователя или `/ban <ID>`)
  и `/unban <ID>`: забаненные игнорируются молча и исключаются из рассылок.

Механика:

- Пост отправляется через `copy_message` во все чаты, которые писали боту
  (LRU-реестр до 10 000 чатов; чаты, заблокировавшие бота, исключаются автоматически).
- Скорость — 20 сообщений/сек; интервал рассылки — от 1 минуты до 30 дней;
  до 20 активных рассылок и 20 шаблонов.
- **Всё в памяти процесса** (файловая система хостинга эфемерна): база чатов,
  рассылки, шаблоны, баны и статистика сбрасываются при перезапуске.
- Отмена ввода в любой момент — `/cancel`.

## Палитры

- **Авто** — mediancut-квантизация (Pillow) с N цветами, по умолчанию 16.
- **Game Boy** — 4 оттенка зелёного: `#0f380f #306230 #8bac0f #9bbc0f`.
- **NES** — классическая палитра консоли NES (2C02), 54 цвета.
- **PICO-8** — 16 официальных цветов фэнтези-консоли (`#ff004d`, `#7e2553`, …).
- **C64** — 16 цветов Commodore 64 (палитра Pepto).
- **Ч/Б** — серая шкала, 8 уровней (с дизерингом — классический ретро-эффект).
- **Ретро CGA** — палитра 1 EGA/CGA: `#000000 #55ffff #ff55ff #ffffff`.

Для фиксированных палитр каждый пиксель заменяется ближайшим цветом палитры
по взвешенному расстоянию redmean (учитывает восприятие), векторно в numpy.
Дизеринг для фиксированных палитр — упорядоченный Bayer 4×4 (пороговая матрица
добавляется к пикселям перед сопоставлением), для «Авто» — Floyd–Steinberg.

## Структура

```
main.py            — точка входа (long polling, проверка BOT_TOKEN)
bot/
  config.py        — конфигурация (os.getenv: BOT_TOKEN, ADMIN_IDS, константы)
  palettes.py      — захардкоженные палитры
  pixelart.py      — чистая обработка изображений (без aiogram)
  state.py         — состояние: настройки (LRU 200, TTL 30 мин) + реестр чатов
  broadcast.py     — чистая логика рассылок (парсер интервалов, расписание)
  admin.py         — админ-панель, флоу рассылок, воркер отправки
  handlers.py      — хэндлеры aiogram 3.x, кнопки, edit_message_media
tests/             — pytest: пикселизация, палитры, LRU/TTL, рассылки, конфиг
```

## Запуск

Единственная обязательная переменная окружения — `BOT_TOKEN` (токен от @BotFather).
Необязательная — `ADMIN_IDS` (Telegram ID админов через запятую).

```bash
pip install -r requirements.txt
BOT_TOKEN=123456:ABC-DEF python main.py
# с админ-панелью:
ADMIN_IDS=123456789 BOT_TOKEN=123456:ABC-DEF python main.py
```

Без `BOT_TOKEN` процесс завершится с понятной ошибкой в логе.

## Деплой на bothost.ru

1. Создай бота у @BotFather и получи токен.
2. Склонируй репозиторий на сервере:
   `git clone https://github.com/bananomonkey/pixel-art-bot.git && cd pixel-art-bot`
3. Установи зависимости:
   `pip install -r requirements.txt` (рекомендуется venv, Python 3.11+).
4. Задай токен и запусти: `BOT_TOKEN=<токен> python main.py`
   (или через панель хостинга: точка входа `main.py`, переменная окружения `BOT_TOKEN`).
5. Допустимо и в Docker: `docker build -t pixel-art-bot . && docker run -e BOT_TOKEN=<токен> pixel-art-bot`.

Особенности хостинга учтены: файловая система эфемерна и диск не используется —
фото, результаты и состояние живут только в памяти (RAM). Исходники хранятся
уменьшенными до 1024 px и в сжатом виде; состояние — LRU на 200 записей
с TTL 30 минут, фоновая чистка каждые 5 минут. Обработка ограничена
семафором (2 одновременных), есть антиспам (1 фото в 3 секунды).

## Ограничения

- Файлы до 20 МБ и до 4000×4000 px; вход уменьшается до 1024 px.
- Анимации (GIF/MP4): берётся первый кадр (MP4 — через imageio-ffmpeg).
- Видеостикеры и анимированные стикеры не поддерживаются.
- Инлайн-режим нужно один раз включить у @BotFather (`/setinline`); превью стилей
  при первом запросе тихо отправляются в личку с ботом (для получения file_id).
- Фото и результаты не сохраняются на диск и не логируются; в логах нет user_id
  и содержимого — только технические записи.
- PNG с прозрачностью: альфа-канал заливается белым.

## Тесты

```bash
pip install pytest
pytest
```

Тестовые изображения генерируются программно (градиенты и круги), внешние
файлы не используются.
